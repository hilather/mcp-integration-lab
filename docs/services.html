Services and how they attach

Each appliance is independently useful. The lab’s job is to wire them, publish them, and tell a client how to reach them.

LabDNS

v1.2.0

Authoritative lab DNS with overrides, wildcards, suffix forwarding, bounded chaos, and an operator console. Over-length names answer on management resolve/explain only; do not add them to lab.test..

Connect. dig @<host> -p 10053 ns1.lab.test — console at :18080/, REST at :18080/v1, MCP at :18080/mcp.

Configure. profiles/<name>/labdns/bootstrap.yaml. Mutations via MCP are ephemeral; dns_state_reset restores the file. Reload: make reload APP=labdns. Remote console Origins go in spec.management.allowedOrigins.

Auth. Bearer in secrets/labdns-token for the management plane. Data plane is plain DNS.

LabLDAP

v0.4.1

Native Go directory (labldapd) plus a control plane. Native is the default engine.

Connect. ldaps://<host>:3636 (SAN directory plus LAB_PUBLIC_HOST as DNS or IP) or LDAP + StartTLS. UI at https://<host>:8443/.

Configure. profiles/<name>/labldap/scenario.yaml. Native engine, lab CA, mutation and password MCP tools enabled. Reload: make reload APP=labldap (re-seeds ephemeral /data).

Auth. Control plane: token-admin. Bind as uid=alice,ou=people,dc=example,dc=test.

TacLab

v1.4.0

TACACS+ (legacy + TLS 1.3) and RADIUS.

Connect. TACACS+ :49 / TLS :300. RADIUS udp :1812/:1813. Control http://<host>:18049/.

Configure. Generated by labgen (YAML and PKI). Profile owns TACLAB_* ports. In LAB_DEV_MODE=true, mcplab secrets pins lab-user passwords and AAA shared secrets from dev-credentials.yaml. Reload: make reload APP=labtacacs.

Auth. Control bearer from api_admin_token. RADIUS shared secret for lab_switches. PASSWORDS.txt for lab users.

49 / 300 · 1812 / 1813 · 18049go-lab-tacacs-mcp

LabMail

v1.0.0-rc.3

Receive-only SMTP sink. Compose service name stays maildev. Relay keys are rejected fail-closed.

Connect. SMTP <host>:1025. UI / /email / /v1 / MCP at <host>:1080.

Configure. profiles/<name>/labmail/bootstrap.yaml. Default originAllowlist: ["*"] so remote inbox JS loads. Reload: make reload APP=maildev (wipes the inbox).

Auth. Web Basic user admin (frozen). Password and MCP bearer minted by mcplab secrets (maildev-web-password, labmail-token, both 0o644).

1025 · 1080go-lab-maildev

LabMITM

v1.4.0

Laboratory HTTP(S) intercepting forward proxy. Data plane is unauthenticated; HTTPS intercept is :443 only (CONNECT to LabLDAP/TacLab TLS is tunnel-not-decrypt). Native /v1 catalog 31 (includes features.get); GET /v1/features is the 11-row hop/accept catalog. SOCKS / inspectFrames / httpAuth stay off.

Connect. HTTP proxy <host>:18888. Inspector / /v1 / MCP at <host>:18088.

Configure. profiles/<name>/labmitm/bootstrap.yaml. Exact Origins (no "*"). Reload: make reload APP=labmitm (wipes captured flows; generate-mode CA rotates; does not re-register).

Auth. Management bearer in secrets/labmitm-token (0o644). Proxy data plane has no Proxy-Authorization (HTTP 407 is opt-in YAML, off here).

18888 · 18088go-lab-mitmproxy

ratarmount-rs

v0.1.28

Writable archive-backed userspace NFSv3 export (empty-root .tar.zst, 15m overlay commit). Remount after commit does not reindex the whole TAR. NFSv4.1 is in the package, this lab stays on v3.

Connect. mount -t nfs -o vers=3,tcp,nolock,port=20490,mountport=20490 <host>:/ /mnt

Configure. NFS_ARCHIVE_DIR and NFS_DATA_DIR in profile.env. Reload: make reload APP=nfs.

Auth. AUTH_SYS. No credential.

labinfo + MCPJungle

Service directory MCP plus the single client gateway. MCPJungle pinned 0.4.6. Operator dashboard is GET / in development mode only (enterprise 404s).

Connect. Gateway http://<host>:8080/mcp or /v0/groups/integration/mcp. labinfo at :18090.

Configure. labinfo/services.yaml and mcpjungle/servers/*.json. Catalog reload: make reload APP=labinfo. Gateway JSON: make register. Gateway container: make reload APP=mcpjungle (re-registers).

Auth. Enterprise (default): secrets/mcp-client-token. Development: open. labinfo secrets only in dev mode.
