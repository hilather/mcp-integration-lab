Services and how they attach

Each appliance is independently useful. The lab’s job is to wire them, publish them, and tell a client how to reach them.

LabDNS — hilather/go-lab-dns

Authoritative lab DNS with overrides, wildcards, suffix forwarding, and bounded chaos.

Connect. dig @ -p 10053 ns1.lab.test — REST at :18080/v1, MCP at :18080/mcp.

Configure. profiles//labdns/bootstrap.yaml. Mutations via MCP are ephemeral; dns_state_reset restores the file.

Auth. Bearer in secrets/labdns-token for the management plane. Data plane is plain DNS.

LabLDAP — hilather/go-lab-ldap-mcp

Native Go directory (labldapd) plus a control plane. Pinned v0.2.2.

Connect. ldaps://:3636 (SAN directory) or LDAP + StartTLS. UI at https://:8443/.

Configure. profiles//labldap/scenario.yaml. Native engine, lab CA, mutation and password MCP tools enabled.

Auth. Control plane: token-admin. Bind as uid=alice,ou=people,dc=example,dc=test.

TacLab — hilather/go-lab-tacacs-mcp

TACACS+ (legacy + TLS 1.3) and RADIUS. Pinned v1.3.0.

Connect. TACACS+ :49 / TLS :300. RADIUS udp :1812/:1813. Control http://:18049/.

Configure. Generated by labgen. Profile owns TACLAB_* ports only.

Auth. Control bearer from api_admin_token. RADIUS shared secret for lab_switches. PASSWORDS.txt for lab users.

maildev — maildev/maildev

Receive-only SMTP sink. Relay flags are rejected fail-closed.

Connect. SMTP :1025. UI/REST :1080 with basic auth.

Configure. profiles//maildev/maildev.yaml.

Auth. Web user MAILDEV_WEB_USER (admin). Password minted by mcplab secrets.

ratarmount-rs — hilather/ratarmount-rs

Writable archive-backed userspace NFSv3 export (empty-root .tar.zst, 15m overlay commit).

Connect. mount -t nfs -o vers=3,tcp,nolock,port=20490,mountport=20490 :/ /mnt

Configure. NFS_ARCHIVE_DIR and NFS_DATA_DIR in profile.env.

Auth. AUTH_SYS. No credential.

labinfo + MCPJungle — mcpjungle/MCPJungle

Service directory MCP plus the single client gateway.

Connect. Gateway http://:8080/mcp or /v0/groups/integration/mcp. labinfo at :18090.

Configure. labinfo/services.yaml and mcpjungle/servers/*.json.

Auth. Enterprise (default): secrets/mcp-client-token. Development: open. labinfo secrets only in dev mode.
