MCP Integration Lab stands up DNS, LDAP, TACACS+, RADIUS, mail, NFS, and HTTP intercept behind a single MCP endpoint. Configuration is YAML and lives in a profile. Runtime state is ephemeral and a restart wipes it.

Ninety seconds

Clone. Make up. Point a client.

Docker Engine 24+ with Compose v2.24.4+, GNU make, and Go 1.26+. First run vendors the service repos and builds images.

  1. make up — clone vendors, mint secrets, build images, start, register.
  2. make reload APP=<app> — recreate one service after a YAML tweak; not a full redeploy.
  3. make smoke — agent-style end-to-end scenario through the gateway.
  4. http://<lab-host>:8080/mcp — attach an MCP client. Enterprise mode needs the minted bearer.
