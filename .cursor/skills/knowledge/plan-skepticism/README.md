# Plan skepticism

Default is disbelief. A plan is a set of claims. Each claim needs a file
you opened, not a summary you remember.

## Guilty until opened

- “`.cursor/skills` already exists” — `ls` it.
- “gitignore will exclude these files” — read `.gitignore`.
- “docs don’t need a changelog” — read this repo’s `AGENTS.md` rule 13.
- “we can clone Origin” — this GitHub cloud VM gets 401 from git-keeper.
  Do not treat a clone as a step.

## Optimism tells

- Investigation listed after prescriptions.
- “verbatim” without a byte source that actually unpacks.
- Scope that quietly includes a vendor pin, `third_party/` edit, or a
  product feature the user forbade.
- Acceptance that skips `make test` on a repo whose gate is `make test`.
- “Helm will fix it” used to skip a required path or a required Cloud
  section in **this** repo.

## Sweeps

Never skip sweep 1. Fresh skeptic each sweep. Cap 3 then **BLOCKED**.
Do not implement while **BLOCKED**.
